Loss waterfall

Structured to protect senior capital first.

Class C (equity) absorbs losses first, then Class B, then Class A. Illustrated below on an assumed US$500m asset value — for illustration only.

ScenarioClass A (US$m)Class B (US$m)Class C (US$m)Total remaining
No loss / impairment300100100US$500m
Impairment of US$150m30050—US$350m
Impairment of US$250m250——US$250m

Illustrative only. Class C absorbs the first US$100m of loss and is fully written down before Class B is impaired; Class A is impaired only after both Class C and Class B are exhausted.
